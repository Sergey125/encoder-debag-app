# BLE Encoder Monitor — Android

Приложение для Android, которое находит по Bluetooth Low Energy плату с
прошивкой энкодера (см. `esp32-h2-ble-encoder` в этом же репозитории),
подключается к ней и отображает вращение в реальном времени: круговой
индикатор положения (0–599) и подробный отладочный лог всех входящих
сообщений.

## Возможности

- **Поиск устройств** — сканирует все BLE-устройства поблизости без
  фильтрации по имени, показывает список с адресом и уровнем сигнала
  (RSSI). Поиск можно остановить в любой момент отдельной кнопкой.
- **Подключение по выбору** — тап по устройству в списке инициирует
  подключение именно к нему.
- **Круговой индикатор** (`EncoderWheelView`) — появляется после
  успешного подключения, спица вращается синхронно с реальным
  положением энкодера (0–599), подсвечивается красным во время
  активного вращения.
- **Отладочный лог** — каждое полученное сообщение (`ENC`, `BTN`, смена
  состояния соединения) записывается с точной датой и временем до
  миллисекунды, новые записи добавляются сверху.
- **Полноэкранный режим** — системные панели (статус-бар, навигация)
  скрыты, временно вызываются свайпом от края экрана.

## Требования

- **Android Studio** (Kotlin, Views — без Jetpack Compose)
- **Min SDK 24**, тестировалось на **compileSdk/targetSdk 35** (AGP 8.7.x)
- Реальный телефон с Bluetooth LE для запуска — **эмулятор не годится**,
  у него нет настоящего Bluetooth-модуля

## Разрешения

Запрашиваются во время выполнения при нажатии «Искать»:

| Android | Разрешения |
|---|---|
| 12+ (API 31+) | `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT` |
| 6–11 (API 23–30) | `ACCESS_FINE_LOCATION` (требование системы для BLE-сканирования) |

## Протокол связи с устройством

Приложение подключается к любому BLE-устройству, реализующему
**Nordic UART Service (NUS)**:

- Service UUID: `6E400001-B5A3-F393-E0A9-E50E24DCCA9E`
- TX Characteristic UUID: `6E400003-B5A3-F393-E0A9-E50E24DCCA9E`

Ожидаемый формат входящих сообщений через нотификации характеристики TX:

ENC:<дельта>\n
BTN:<событие>\n


где `<дельта>` — знаковое целое число шагов энкодера с прошлой отправки
(например, `ENC:3` или `ENC:-1`). Приложение само накапливает эти дельты
в абсолютную позицию 0–599 с циклическим переходом через границу.

## Как это работает изнутри

1. `BleEncoderClient.startScan()` запускает сканирование BLE **без**
   `ScanFilter` — в колбэк `onScanResult` попадают вообще все
   рекламирующиеся поблизости устройства, каждое новое передаётся в
   `onDeviceFound`.
2. `DeviceAdapter` отображает их списком; повторные объявления одного и
   того же устройства обновляют существующую строку (`addOrUpdate`), а
   не плодят дубли.
3. При тапе по устройству вызывается `BleEncoderClient.connectTo(device)`
   — сканирование останавливается, начинается подключение по GATT.
4. После обнаружения сервисов включается подписка на нотификации
   TX-характеристики; входящие байты собираются в буфер и разбиваются
   по `\n`, каждая строка парсится в `parseLine()`.
5. Разобранные события идут в колбэки `onEncoder` / `onButton` /
   `onState`, которые в `MainActivity` обновляют UI: колесо, статус,
   видимость кнопок «Искать»/«Стоп», лог.

## Сборка и запуск

1. Откройте проект в Android Studio, дождитесь синхронизации Gradle.
2. Подключите телефон по USB, включите отладку по USB в настройках
   разработчика.
3. Запустите на устройстве (зелёный треугольник или `Shift+F10`).
4. Нажмите **«Искать»**, разрешите доступ к Bluetooth, дождитесь
   появления устройства `encoder` в списке (или другого совместимого
   BLE-устройства), тапните по нему.

## Известные ограничения

- Список найденных устройств не фильтруется по имени — при большом
  количестве BLE-устройств поблизости (наушники, фитнес-браслеты и
  т. п.) список может получиться длинным, приходится искать нужное
  вручную.
- Позиция энкодера хранится только в памяти приложения и сбрасывается
  при каждом новом подключении (`wheelPosition = 0`) — синхронизации с
  накопленным состоянием на самом устройстве нет.
- При потере части BLE-нотификаций накопленная позиция может разойтись
  с реальным положением энкодера до следующего переподключения.
