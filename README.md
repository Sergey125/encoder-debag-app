# BLE Encoder — вращающийся энкодер по Bluetooth LE

Проект из двух частей:

1. **Прошивка** для платы ESP32-H2 — считывает вращение поворотного энкодера
   через аппаратный блок PCNT и рассылает позицию по Bluetooth LE в виде
   текстового UART-подобного сервиса (Nordic UART Service).
2. **Android-приложение** — сканирует ближайшие BLE-устройства, подключается
   к энкодеру и отображает положение колеса (0–599) в реальном времени, плюс
   отладочный лог всех входящих сообщений с точным временем.

## Аппаратная часть

- Плата: **ESP32-H2**
- Энкодер подключён к пинам:
  - `CLK` → GPIO3
  - `DT`  → GPIO4
- Вращение считывается аппаратным блоком **PCNT** (Pulse Counter), без
  нагрузки на процессор — устойчиво держит высокоскоростные энкодеры
  (проверено на 600 импульсов/оборот).
- Позиция передаётся по кругу: `0 → 599 → 0`.
- Формат сообщений по BLE: `ENC:<дельта>\n` — дельта шагов с последнего
  замера, накопление в абсолютную позицию делает приложение.
- Имя устройства при рекламе: **`encoder`**.
- UUID сервиса и характеристики — стандартные для Nordic UART Service (NUS),
  поэтому прошивку можно проверить любым готовым BLE-терминалом
  (например, **nRF Connect**) без установки собственного приложения.

### Требуемые библиотеки Arduino IDE

- `NimBLEDevice` (NimBLE-Arduino, версия 2.x)
- `Adafruit_NeoPixel` — для адресного светодиода индикации состояния

### Настройки безопасности

По умолчанию `REQUIRE_ENCRYPTION` выключен (`0`) для упрощения отладки.
При включении (`1`) подключение потребует PIN **123456**.

## Android-приложение

- **Язык:** Kotlin
- **Min SDK:** 24
- **Compile/Target SDK:** 35 (AGP 8.7.x)

### Возможности

- Сканирование всех BLE-устройств поблизости, без фильтра по имени —
  список с адресом и уровнем сигнала (RSSI), можно остановить поиск в
  любой момент.
- Подключение к выбранному устройству по тапу в списке.
- После подключения — круговой индикатор положения энкодера (0–599) со
  спицей, вращающейся синхронно с реальным вращением, и подсветкой
  красным при активном движении.
- Отладочный лог всех событий (`ENC`, `BTN`, смена состояния соединения)
  с датой и временем до миллисекунды.
- Полноэкранный режим — системные панели скрыты, доступны временно по
  свайпу от края экрана.

### Структура

app/src/main/java/com/example/encoder/
├── MainActivity.kt — экран приложения, связывает всё воедино
├── BleEncoderClient.kt — сканирование, подключение, разбор BLE-сообщений
├── BleState.kt — состояния соединения (Idle/Scanning/Connecting/Ready/Error)
├── DeviceAdapter.kt — список найденных устройств (RecyclerView)
└── EncoderWheelView.kt — кастомный View кругового индикатора

app/src/main/res/layout/
├── activity_main.xml
└── item_device.xml


### Разрешения (манифест)

- `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT` — Android 12+
- `BLUETOOTH`, `BLUETOOTH_ADMIN`, `ACCESS_FINE_LOCATION` — Android 6–11

## Сборка

1. Прошивка: Arduino IDE, плата **ESP32-H2**, ядро `esp32` версии 3.x.
2. Приложение: Android Studio, реальный телефон для отладки (эмулятор не
   поддерживает Bluetooth), отладка по USB.

## Известные ограничения

- Список BLE-устройств не фильтруется по имени — при большом количестве
  BLE-устройств поблизости (наушники, фитнес-браслеты и т. п.) список
  может быть длинным.
- Прошивка передаёт дельту шагов, а не абсолютную позицию — при потере
  части нотификаций накопленное значение в приложении может разойтись с
  реальным положением энкодера до следующего переподключения (сброс
  позиции происходит при каждом новом подключении).
